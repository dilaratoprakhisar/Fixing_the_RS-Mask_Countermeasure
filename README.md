# Picking up the Fallen Mask: Breaking and Fixing the RS-Mask Countermeasure

VHDL/Verilog hardware implementation of the fixed RS-Mask countermeasure for the AES S-box.

## Repository structure

All files are in the repository root. 

## Requirements

- **Languages:** VHDL-93 and Verilog-2001 (mixed-language design)

## Build and run

Clone the repository:

```bash
git clone https://github.com/dilaratoprakhisar/Fixing_the_RS-Mask_Countermeasure.git
cd Fixing_the_RS-Mask_Countermeasure
```
